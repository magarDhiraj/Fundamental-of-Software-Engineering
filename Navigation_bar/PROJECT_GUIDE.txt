HTML & CSS ASSIGNMENT — STEP-BY-STEP GUIDE

1. CREATE THE FOLDER
   Create a folder named:
   html-css-assignment

2. CREATE THE FILES/FOLDERS
   html-css-assignment/
   ├── index.html
   ├── css/
   │   └── style.css
   ├── images/
   ├── screenshots/
   ├── README.md
   └── .gitignore

3. OPEN THE PROJECT
   Open the html-css-assignment folder in VS Code.

4. RUN THE WEBSITE
   Open index.html in your browser.
   If you use the VS Code Live Server extension, right-click index.html and choose:
   Open with Live Server

5. TEST PART A — NAVIGATION BAR
   Check that these items appear:
   LearnHub, Home, About, Courses, Contact, Resources.
   Move the mouse over the links and confirm that the hover effect appears.

6. TEST PART B — CARD DESIGN
   Each card should contain:
   - Image
   - Category/tag
   - Title
   - Description
   - Extra information
   - View Course button
   - Hover effect

7. TEST PART C — MULTIPLE CARD LAYOUT
   There are 6 course cards.
   Desktop: 3 cards per row.
   Tablet: 2 cards per row.
   Mobile: 1 card per row.

8. TAKE THE REQUIRED SCREENSHOTS
   Save these inside screenshots/:
   navigation-bar.png
   card-design.png
   card-layout.png
   responsive-design.png

9. UPDATE README.md
   Replace the placeholders for Student ID, Course/Module and Level.
   Keep only the learning resources you actually used.
   Add your real GitHub URL.
   Do not claim to have used a resource that you did not use.

10. CREATE GITHUB REPOSITORY
   In GitHub, create a new repository named:
   html-css-assignment

11. OPEN VS CODE TERMINAL
   Run:

   git init
   git add .
   git commit -m "Complete HTML CSS practical assignment"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPOSITORY_URL
   git push -u origin main

   Replace YOUR_GITHUB_REPOSITORY_URL with your own GitHub repository URL.

12. FINAL CHECK BEFORE SUBMISSION
   - Navigation bar completed
   - Hover effects work
   - At least 6 cards
   - Images, titles, descriptions and buttons included
   - Flexbox/Grid used
   - Responsive layout works
   - 4 screenshots added
   - README completed
   - Learning resources documented honestly
   - AI use disclosed if applicable
   - GitHub repository pushed successfully
   - You can explain the code
